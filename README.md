# Experiment tracking with MLflow

A small worked example of tracking machine-learning experiments with MLflow, so runs, parameters, metrics and models are recorded instead of lost in notebook cells.

## What's inside

- Preprocessing a tabular dataset: binary encoding, missing-value checks, train/test split
- Training and cross-validating a scikit-learn classifier
- Logging parameters, metrics, artifacts (confusion matrix) and the model to MLflow
- Browsing runs with `mlflow ui`

## Files

- `Experiment tracking.ipynb` — the walkthrough
- `dsml_feb_mlops_exp_tracking.ipynb` — shorter version of the same
- `mlruns/` — MLflow run store generated by the notebooks

Run `mlflow ui` in this folder to open the tracking dashboard.
